# TicketFlow Assistant

https://ticketcarecenter3.lovable.app/tickets
buatkan aplikasi persis seperti web tersebut. dan lakukan beberapa perubahan :
1. pada menu filter status, tambahkan pilihan Pending Transport, Pending Spare, Pending Customer dan Pending

2. hilangkan menu PDF dan Print

3. logo tempat sampah diganti dengan cek box untuk pilihan hapus. sebelum hapus munculkan popup konfirmasi.

4. munculkan menu rollback. ketika ada data yg terdelet bisa dikembalikan

5. jika ada penulisan warp text, tulisan pada kolom keterangan, customer, nama lokasi, indikasi gangguan  posisi menjadi align center left (menyesuaikan banyaknya isi last update)

6. ganti filter teknisi menjadi filter Layanan. dan tambhakan pilihan AIS, VIS, SBS, Mangostar, Star Data, Star Data Lite

7. ketika input tiket baru, posisinya menjadi nomor 1

8. tambahkan kolom Nomor pada menu daftar tiket

9. untuk isi dari kolom aksi, status customer, tiket mantools, tiket noxis, layanan, jenis tiket, asal gangguan regional, tim sem, open by, tanggal open, tanggal close dan durasi dibuat align center

9. tambahkan notifikasi ke telegram saya jika setiap kali input tiket baru
